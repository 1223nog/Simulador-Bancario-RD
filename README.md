# Simulador Bancario - República Dominicana
Programa en C++ para calcular cuotas fijas de préstamos personales
basado en la realidad bancaria de República Dominicana.

## Características
Cálculo de cuota fija (sistema francés)
Interés + Seguro de vida + Comisión de apertura
Generación de factura para el cliente
Presentación profesional

## Cómo usar
Descargar el archivo .exe
Ejecutar el programa
Ingresar los datos del préstamo
